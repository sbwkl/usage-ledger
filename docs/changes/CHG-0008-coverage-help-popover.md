# CHG-0008 口径说明改为问号帮助层

类型：CHG
状态：已验证
Owner：wayne
所属模块/入口：`usage html` / `src/usage_ledger/html_report.py`
功能卡：[REQ-0001 本地 AI 编码工具用量台账](../requirements/REQ-0001-usage-ledger.md)
关联：[CHG-0005 HTML 报表展示与交互](CHG-0005-html-report-display-and-interaction.md)、[REQ-0001 R30 / R44](../requirements/REQ-0001-usage-ledger.md)

## 1. 摘要

“口径与数据覆盖”当前是报告流中的一张独立可折叠卡片，展开后是一大段解释文字，占用首屏并打断阅读。本 CHG 删除该卡片，改为页首问号按钮；点击后在浮层中展示同一组覆盖 / 刷新状态 / 生成时间 / 口径说明，默认不占据报告布局。

## 2. 变更理由与证据

- 对应功能卡的问题/目标：REQ-0001 G1（在一个视图里回答用量问题）、R15（口径边界可见）。
- 触发原因：用户 2026-11-16 反馈“解释类型的文本不要单独作为一块放置在报告中，使用形似问号的 icon，点击后展开解释文本”。
- 证据：
  1. 当前 `coverage-block` 是一张独立 `details.card`，位于筛选区与报告之间；即使折叠也占一行，展开后包含 10+ 段说明。
  2. 其内容可分为高频状态（覆盖范围、Trae 刷新状态、生成时间）与低频解释（术语、来源、隐私、行数口径）；低频解释不应占据主阅读流。
  3. 当前无 Esc / 点击外部关闭 / 焦点返回；作为独立块也没有 `aria-expanded` 状态。
- 不做的后果：首屏继续被解释文字占据；用户需要在长卡片中寻找刷新状态；说明内容的交互不符合“按需展开”的阅读习惯。

## 3. 行为 / AC delta

- 修改：R30 从“独立可折叠块”改为“问号按钮打开的帮助层”。
- 新增：R44（帮助层的图标入口、展开状态、关闭方式、焦点返回、告警点、移动端布局）。
- 预期行为：
  - 页首 `数据截至` 旁显示圆形 `?` 按钮；帮助层默认关闭，不占据报告卡片流。
  - 点击按钮打开浮层，展示覆盖说明、Trae 状态、页脚补充说明和生成时间；再次点击、点击“关闭”、按 Escape 或点击外部关闭。
  - 打开/关闭同步 `aria-expanded`；通过 Escape 或关闭按钮关闭后焦点回到问号按钮。
  - Trae 状态为 warn / error 时，问号按钮显示琥珀色提醒点，避免隐藏刷新失败。
  - ≤640px 时浮层改为固定在视口内的可滚动面板，不覆盖筛选抽屉的交互。
- 非目标：不改说明文字的具体数据口径；不改 Trae / Qoder 采集；不新增网络请求；不把说明内容放入主报告卡片。

## 4. 影响范围与非目标

- 受影响：HTML 报表头部布局、覆盖说明 DOM、交互事件、移动端浮层样式、相关测试。
- 不影响：payload 结构、后端覆盖率计算、CLI 输出。
- 兼容性：旧报告是静态文件；新报告只改变展示层，无数据迁移。

## 5. 验证与观测

- 自动化：`HtmlCoverageBlockTest` 覆盖标记、展开状态、焦点返回、告警点；全量测试 / AC map / 覆盖率门禁。
- 手工：1440px 与 500px 下打开/关闭帮助层、Escape、点击外部；Trae 刷新失败时检查提醒点；确认首屏不再出现独立口径卡片。
- 指标 / 日志：无新增埋点；以 DOM 状态与截图为准。
- 结果与证据：
  - 自动化：`python3 -m unittest discover -s tests -t .` → 277 tests / 0 failures / 0 errors / 0 skips；`HtmlCoverageBlockTest` 覆盖问号入口、`aria-expanded`、焦点返回、告警点；AC map 44 criteria / 92 identifiers；覆盖率 93.3%。
  - 手工：`/tmp/chg8-report.html` 在 1440px 与 500px 下首屏不再有独立口径卡片；点击 `?` 打开浮层，Escape 关闭并把焦点还给按钮，点击外部关闭；Trae 状态告警时按钮显示提醒点（Node 断言）。

## 6. 回滚方案

- 回滚方式：恢复 `coverage-block` 独立卡片及原有 details 交互。
- 数据兼容：纯展示层，无迁移。
- 回滚验证：生成报告确认独立卡片恢复，测试回到旧断言。

## 7. 风险与未决问题

- 风险：说明文字隐藏后，用户可能忽略 Trae 刷新失败。缓解：问号按钮告警点 + 浮层首段保留状态。
- 风险：移动端浮层可能遮挡筛选抽屉。缓解：固定面板与抽屉 z-index 分离，Escape 关闭当前层。
- 未决：是否把“生成时间”移到页脚；本 CHG 先保留在帮助层底部。
